Репозиторий QR Scanner (с фонариком)
Описание
QR Scanner – это набор консольных утилит на 8 языках программирования для сканирования QR-кодов с использованием веб-камеры. Программа захватывает видео с камеры, обнаруживает и декодирует QR-коды в реальном времени, а также позволяет включать фонарик (вспышку) для подсветки в темноте.

Проект создан как тестовый репозиторий для демонстрации решения одной задачи на разных языках с использованием идиоматичных подходов и продвинутых возможностей.

Возможности
Сканирование QR-кодов в реальном времени через веб-камеру.

Автоматическое распознавание – при обнаружении кода результат выводится в консоль и копируется в буфер обмена (опционально).

Управление фонариком – включение/выключение вспышки камеры (поддерживается на большинстве платформ).

Сохранение результатов в файл (опция --output).

Несколько режимов работы:

scan – непрерывное сканирование с выводом результатов.

once – сканирование одного кода и завершение.

flash – включить фонарик на указанное время.

Графический интерфейс (в некоторых реализациях) – окно с видеопотоком и подсветкой найденных кодов.

Поддержка различных форматов – QR-коды, а также Data Matrix, Aztec, PDF417 (в зависимости от библиотеки).

Кроссплатформенность – работает на Windows, macOS, Linux.

Установка и запуск
Каждый файл является самостоятельной программой. Для запуска необходима соответствующая среда выполнения и установка зависимостей.

Язык	Установка	Запуск
Python	Python 3.8+ и pip install opencv-python pyzbar	python qr_scanner.py [опции]
JavaScript	Node.js 14+ и npm install qrcode-reader jimp	node qr_scanner.js [опции]
TypeScript	Node.js + npm install -g ts-node typescript и npm install qrcode-reader jimp	ts-node qr_scanner.ts [опции]
Go	Go 1.18+ и библиотека github.com/makiuchi-d/gozxing	go run qr_scanner.go [опции]
Java	JDK 11+ и библиотека zxing (core + javase)	javac -cp .:zxing-core-*.jar:zxing-javase-*.jar QrScanner.java && java -cp .:zxing-core-*.jar:zxing-javase-*.jar QrScanner [опции]
C#	.NET SDK 6.0+ и пакет ZXing.Net	dotnet run или csc
PHP	PHP 8.0+ и расширение imagick	php qr_scanner.php [опции]
Ruby	Ruby 2.7+ и gem install rqrcode zbar	ruby qr_scanner.rb [опции]
Примечание: Для работы с камерой требуется разрешение на доступ к ней. На некоторых платформах может потребоваться установка дополнительных драйверов или библиотек (например, v4l-utils на Linux).

Использование
text
qr_scanner [command] [options]
Команды
Команда	Описание
scan	Запустить непрерывное сканирование (по умолчанию).
once	Сканировать один QR-код и завершить.
flash	Включить фонарик на указанное время (в секундах).
help	Показать справку.
Опции
Опция	Описание
-c, --camera <id>	ID камеры (по умолчанию 0).
-o, --output <file>	Сохранять результаты в файл (каждый код на новой строке).
--copy	Копировать результат в буфер обмена.
--flash	Включить фонарик во время сканирования.
--no-gui	Отключить графическое окно (только консоль).
-h, --help	Показать справку.
Примеры
bash
# Запустить сканирование с фонариком и копированием в буфер
python qr_scanner.py scan --flash --copy

# Сканировать один код и сохранить в файл
node qr_scanner.js once -o result.txt

# Включить фонарик на 5 секунд
go run qr_scanner.go flash 5
Особенности реализаций
Python – использует OpenCV для захвата видео и pyzbar для декодирования QR-кодов.

JavaScript – использует qrcode-reader и jimp для обработки кадров из камеры через getUserMedia.

TypeScript – аналогично JavaScript, но с строгой типизацией.

Go – использует библиотеку gozxing для декодирования и gocv для захвата видео (или mjpg-streamer).

Java – использует ZXing (Zebra Crossing) для декодирования и JavaCV для захвата видео.

C# – использует ZXing.Net и Emgu.CV (или AForge.NET) для работы с камерой.

PHP – использует расширение imagick и zbar через exec (для демонстрации).

Ruby – использует zbar и rqrcode для генерации (для тестов).

Во всех реализациях реализована обработка ошибок, управление фонариком (где возможно) и вывод результатов в удобочитаемом формате.
